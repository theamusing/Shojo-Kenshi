# 少女剑士 · Shojo Kenshi

原生 JavaScript + Canvas 2D 的横版像素剑斗游戏，无第三方运行依赖。需要 Node.js 22 或以上。

## 本地运行

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。无需 npm install，请通过 HTTP 服务访问，避免直接双击 HTML 时的模块加载限制。

- **A / D**：左右移动，松开回到 idle，同时按下则停止。切出窗口自动清除按键。
- **Esc**：暂停／继续整个游戏，也可点击页面上的暂停／继续按钮。暂停会冻结双方动作、Boss 决策、击退、闪白、火花和环境动画；恢复时从原进度继续，不补算暂停时间。暂停／恢复会清除未处理输入，移动需重新按键。
- 首次按游戏键或点击舞台后开启声音。Esc 暂停菜单内可分别调节音乐、音效音量或静音，设置保存在本机浏览器；Esc 暂停和切换到后台时声音一同暂停。
- 玩家和 Boss 有独立、朝向无关的实体碰撞体积；玩家无法穿过或推动 Boss。Boss 行走可以推动玩家，但玩家被推到场地边缘时 Boss 也会停下，不会挤穿。
- **J**：待机／跑动时开始攻击。第 1～7 帧为第一段，期间再按一次 J 则衔接第 8～15 帧；第二段期间再按 J，则在第 15 帧结束后回到第一段。每段只缓存一次续击，长按不会自动连击。原图第 16 帧保留但不播放，第 15 帧仅用于收尾，无攻击判定。
- 第一段未续击时，在原第 7 帧播放完成后追加「第 7 帧 → 第 6 帧」收招，各占 1/16 秒，收招无攻击判定。收招中按 J 立即进入第二段第 8 帧，按 K 仍可打断为格挡；否则收招结束后恢复移动／待机。
- **K**：待机、跑动或攻击中发动格挡，随机播放 defend_1 / defend_2；立即打断攻击并清空连击缓存。格挡动作的任意一帧都可挡住 Boss 攻击，并在当前刀刃位置产生白金闪光与橙色火花。普通格挡成功时向远离 Boss 的方向轻退，最多约 18 像素，少于普通受击的约 45 像素；不重播或延长格挡动画，剩余格挡时间较短时后退距离也较短，动作结束立即停止。成功挡住跳劈时，自动转为 defend_3 跪地滑行（12 帧、16fps），不受伤、不闪白，但承受与跳劈命中相同的击退距离。格挡及滑行期间不能用 A / D / J / K 打断。
- 优先级：受击 > 格挡 > 攻击 > 移动／待机。同一更新内收到 J 和 K 时优先格挡。攻击／格挡期间锁定方向键移动与朝向（仍可被 Boss 推动），结束后根据当前 A / D 输入恢复移动或待机。攻击第 5～7 帧、第 12～14 帧各按出招朝向向前踏步约 24 像素，受 Boss 体积和场地边缘阻挡，不能推动 Boss；第一段收招回放不重复踏步，格挡或受击打断时立即停止踏步。
- 玩家没挡住时闪白、强制面朝 Boss、向远离 Boss 的方向击退，播放 hit 前 8 帧（12fps）。受击期间 A / D / J / K 都不能打断；再次被命中会重新开始受击和击退，没有额外无敌时间。
- **H**：显示／隐藏判定框，蓝色为双方身体受击框，黄色虚线为实体碰撞体积，红色为双方武器攻击框。玩家攻击框在出招第 6、14 帧有效；收招回放第 6 帧无攻击框。Boss 判定见下表。
- 玩家武器命中 Boss 身体时，Boss 白色剪影闪烁 1/16 秒（一帧攻击动画），每段攻击最多命中同一目标一次。即使渲染跨过有效帧也会检测命中。
- Boss 开场保证待机 3 秒，随后自动追近、后撤、待机或出招；普通受伤只闪白，韧性打满或血量耗尽会中断招式。
- 触屏显示左右移动、攻击和格挡按钮。
- 页面只保留自适应 16:9 游戏画面。操作说明出现在玩家上方，约 3 秒后消失；触屏操作也位于画面内。
- 死亡结算后按任意键或点击任意位置重开，胜利结算可点击「再战一场」或按任意键。重开恢复血量、韧性、站位、计时和开场保护。

## 血量、韧性与胜负

- 玩家 100 血，左上角短红条；普通模式 Boss 600 血，困难模式 1000 血，下方居中的红条。画面不显示数值。
- 首次击败 Boss 并完成战败动画后解锁困难模式；解锁记录和所选难度保存在本机浏览器。胜利界面可直接挑战困难，Esc 设置菜单也可选择难度并点击「重新开始」生效；继续游戏保持本局难度。困难模式在 Boss 条下方显示红色「难」字。
- 玩家第一段攻击造成 15 伤害，第二段造成 20；每次有效攻击判定只结算一次。
- Boss 一式／突刺造成 15 伤害，二式每段 10，跳劈 30。格挡完全免伤。
- Boss 普通模式韧性上限 60，困难模式 80，细黄色条从中心向两侧增长；每次普通格挡增加 5，跳劈格挡增加 10，平时不自动消退。
- 成功弹反带来轻微、短促的屏幕抖动，HUD 保持稳定；最后一次击满韧性的弹反强化为更大的闪光和 88 条火花，音效增益额外乘 1.3，并从 Boss 身体向外扩散三圈带画面折射的波纹。暂停冻结特效，重开清除残留；系统启用减少动态效果时关闭屏幕抖动。
- 韧性满后立即打断招式，播放 boss_down 的 10 帧；保持末帧 3 秒，期间可持续攻击，韧性均匀降至 0，然后播放 boss_up 的 11 帧再返回 AI。倒地、跪地保持和起身期间均受到正常伤害（第一段 15、第二段 20）。
- Boss 名称为「红盔武士」。血量归零时中断当前动作并停止新攻击判定，触发 0.65 秒致命一刀演出：白色背景、黑色玩家、灰色 Boss，双方动作以 20% 速度继续，最后 0.15 秒淡回正常场景。随后以正常速度播完 boss_defeated，Boss 饱和度降至 15%；显示战斗时长及是否无伤。演出不计入战斗时间，Esc 可暂停，重开恢复正常颜色。格挡不影响无伤记录。
- 玩家血量归零时锁定 hit 前 8 帧，以四分之一速度播放，场景变灰；播完后显示红色「死」与重新开始提示。死亡过程不能攻击或格挡。
- 战斗时间从本局可操作时开始（含开场 3 秒），暂停、后台、死亡慢动作及胜利演出不计时。Esc 同时冻结倒地恢复、死亡慢动作和胜利演出。

## Boss 决策与招式

Boss 移速 96 像素／秒，玩家为 160。Boss 跑动动画 8fps，其他动作均为 12fps。移动与待机时始终朝向玩家；攻击从起手到结束固定朝向。开场 3 秒保护结束后进入正常决策，每次待机／移动决策至少保持 0.5 秒，额外随机延长 0～0.35 秒。

- 远距离：中心距离大于 210 且不超过 520 像素、上一招不是跳劈时，10% 跳劈、70% 移动、20% 待机；其他远距离情况为 80% 移动、20% 待机。
- 中心距离不超过 210 像素：基础权重为 62% 攻击、23% 移动、15% 待机。
- Boss 血量降至一半及以下（普通 ≤300，困难 ≤500）时，近距离攻击概率增加 16 个百分点（无墙角修正时为 78%），移动与待机按原比例缩减；远距离跳劈概率从 10% 提高至 18%，突刺后接跳劈从 30% 提高至 45%。后撤方向规则、至少 0.5 秒的决策间隔、跳劈后必定待机及禁止连续跳劈保持不变。
- Boss 每次受击后有 28% 概率选择防御：待机／移动时立即进入，出招时先完成招式再防御；跳劈仍先经过强制待机。触发防御的那一刀按原状态结算，未选中防御时继续原动作和正常决策。
- boss_defend 每次进入时随机持续 0.5～0.9 秒，动画保持 12fps；短防御提前结束，超过 9 帧的时长保持最后姿势。反复挨打不会重抽或延长防御。期间玩家两段攻击只造成 30% 伤害（4.5／6），不增加韧性，防御结束必定选择一个普通攻击反击。开场保护、跪倒、起身和战败不触发防御反应。
- 砍中防御中的 Boss 时，用较低、较轻的双层 parry 替代砍肉声：相对玩家弹反，播放速率乘 0.75、增益乘 0.45，保留随机变化，不压低 BGM。
- 左侧靠边规则：玩家在 Boss 左侧时，Boss 从 x=480 到 x=140 越靠左，适当降低攻击权重、增加移动权重。选中移动后，靠边后撤概率从 x=480 的 0% 提升至左侧三分之一边界 x=320 的 95%，到 x=140 时达到 98%；进入左侧三分之一后，主动向左逼近的概率仅 5%～2%。玩家在 Boss 右侧时不施加此限制，以便 Boss 走离左墙。动作持续时间仍为 0.5～0.85 秒。
- 玩家贴近（中心距离不超过 180 像素）时，Boss 选中移动后，基础后退概率为右半场（x≥480）55%、左半场 60%，再与靠边后撤概率取较大值。后撤仍面向玩家，只调整移动方向；攻击及跳劈规则保持原样，近距离仍可正常出招。
- 三个普通招式随机选择，刚用过的招式权重略降，但仍允许同招连发。普通招式结束后重新决策；突刺 attack_3 结束时，距离不超过 520 像素则先有 30% 概率衔接跳劈。
- 跳劈 jump_attack 全程 12fps，第 4～12 帧以 360 像素／秒向出招方向追近，最多移动 270 像素，靠近到中心距离 120 像素时停止追近；全程锁定朝向。第 13 帧产生一次宽大的下劈判定。未格挡进入 hit 并闪白，成功格挡进入 defend_3；两种结果均击退约 119 像素（普通受击约 45 像素），碰到场地边缘会停下。
- 跳劈完整播放结束后，必定待机一轮（0.5～0.85 秒）。再次跳劈前必须先使用其他攻击，避免连续跳劈。

| 招式 | 攻击判定帧（从 1 计数） | 说明 |
| --- | --- | --- |
| attack_1 | 13 | 举剑下劈，放宽下方范围以覆盖较矮玩家 |
| attack_2 | 12、18 | 两次独立判定，每次各需一次格挡；可再次命中受击中的玩家 |
| attack_3 | 11 | 突刺，使用较宽大的矩形判定 |
| jump_attack | 13 | 跳跃下劈，命中或格挡均造成强击退，格挡触发跪地滑行 |

可在 `src/boss.js` 的 `BOSS_CONFIG` 调整速度、距离阈值、决策时间与概率。玩家弹反产生大范围暖色光晕、白热中心和 48 条带拖尾的金属火花，闪光约 0.16 秒、火花最长 0.52 秒；跳劈弹反强化为 64 条火花与更大闪光。Boss 挡刀时在刀刃位置播放稍弱的同类特效（20 条火花，光晕半径 42，亮度系数 0.72，最长 0.34 秒）。火花受阻力与重力影响，由亮白金色逐渐冷却为橙色；每次攻击判定对同一目标最多结算一次。

## 音乐与音效

配乐《月下交锋》保持原有的 Web Audio 合成版本：132 BPM、32 小节（约 58 秒）循环，包含太鼓、鼓边敲击、拨弦、笛声、弦乐和锣，后半段增加密度。战斗音效使用随游戏托管的 CC0 录音素材及用户提供的 hit3，实际加载 4 个 PCM WAV 文件；不依赖第三方音频服务或外链播放。

- 挥刀：使用 qubodup 的真实竹棒挥动录音。玩家固定使用 swing-4，基础播放速率 1.25、增益 0.28；Boss 固定使用 swing-2，速率 0.82、增益 0.28。收招回放、动画预览和提前格挡取消不会重复播放。
- 命中：双方命中均只播放 `hit-3.wav`，基础播放速率 0.78、增益恢复至 0.68；挥空不播放。`hit-1.wav` 和 `hit-2.wav` 仅保留为素材备份，游戏不加载或播放。
- hit3：保留用户原始 `hit-3.mp3`，处理后生成 `hit-3.wav`。保留重音，随后平滑压低尾部约 14dB，叠加短促、低音量的湿润撞击纹理；最终低通放宽为 4.8kHz 二阶，恢复切入细节，避免低速播放时过闷；处理后长 0.65 秒。原始素材授权信息未提供，湿润纹理为 CC0。
- 弹反：仅使用 StarNinjas 的 parry-1，高低双音同时播放：高音基础速率 1.17，低音速率 0.765；两层共享每次随机变化，音量占比分别为 65% 和 35%，总增益恢复为 1.65。弹反瞬间短暂压低配乐，让金属撞击更突出。
- 跳劈：挥刀、命中、弹反的增益均为对应普通动作的 1.4 倍；挥刀和命中的速率乘 0.9，弹反仅乘 0.96，保留明亮的金属音调。
- 每次随机改变音量（±8%）与音调：挥刀 ±2 半音、命中 −2～+1 半音、弹反 ±1.2 半音。命中、角色挥刀、Boss 挥刀和弹反各固定一段素材。配乐按固定音高演奏，保持旋律与和声。
- 根据发生位置轻微左右声像定位，输出带动态压缩，限制叠音峰值。音效并发上限 16，结束后释放节点；重置会清除残留音效。
- 音效在首次交互时下载并解码缓存；加载失败会显示提示，点击舞台只重试失败文件，BGM 和游戏仍可运行，不退回旧的合成音效。

素材页面：[挥刀](https://opengameart.org/content/swish-bamboo-stick-weapon-swhoshes)、[剑击 1](https://freesound.org/people/CogFireStudios/sounds/547035/)、[剑击 2](https://freesound.org/people/CogFireStudios/sounds/547036/)、[刀刃碰撞](https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes)。均标注 CC0，允许游戏使用、修改与分发。完整作者、下载链接与处理记录见 `assets/audio/CREDITS.txt` 和 `manifest.json`，两者随 GitHub Pages 一起发布。`scripts/prepare-sfx.py` 可从缓存原始素材重新制作游戏用 WAV；它仅用于素材处理，运行和构建游戏无需 Python。

## 代码结构

- `src/animations.js`：图集配置、异步图片加载、基于时间的动画播放器。4 列，按行播放，显式有效帧数排除空白格。支持帧区间，边界保留未消耗时间，确保末帧完整播放且衔接不丢时间。
- `src/actor.js`：状态机、两段攻击与输入缓存、格挡打断、角色移动、预览控制和带锚点的精灵渲染。动作结束恢复移动／待机，defeated 保持末帧。
- `src/input.js`：按键按下沿、自动重复过滤及一次性动作事件队列。
- `src/combat.js`：身体与武器矩形、坐标转换、命中检测、单段去重与判定框绘制。
- `src/physics.js`：实体碰撞、玩家阻挡与 Boss 推挤，包含场地边缘约束。
- `src/boss.js`：Boss 决策计时、距离与墙角概率、招式选择及攻击推进。
- `src/duel.js`：血量、韧性、击倒／起身、开场保护、计时与胜负流程；以不大于 1/120 秒的子步推进战斗，在动画更新后统一结算伤害与状态切换。
- `src/effects.js`：按格挡姿势定位刀刃的闪光、火花、弹反抖动与韧性击破折射波纹。
- `src/progress.js`：困难解锁和所选难度的本地保存；存储不可用时仍可在本次页面内正常游玩。
- `src/audio.js`：音频启用、配乐调度、随机变调、音量与静音、弹反压低配乐、暂停联动。
- `src/sound-design.js`：保留原有合成乐器与 32 小节配乐谱面，以及音效随机音高范围。
- `assets/audio/`：录音音效、CC0 来源与作者说明、逐文件来源及校验值。
- `src/stage.js`：程序绘制的像素舞台、地面基准与环境动画。
- `src/main.js`：输入、游戏循环、HUD、暂停菜单和胜负界面。
- `test/animation.test.js`：时间推进、状态切换、边界、锚点和真实 PNG 帧内容验证。
- `test/combat.test.js`：连击边界、输入优先级、格挡中断、移动锁定和按键重复验证。
- `test/hitboxes.test.js`：有效帧、朝向与距离、跨帧命中、重复命中限制、闪白时长和 H 键验证。
- `test/physics-recovery.test.js`：双向实体阻挡、防穿透、收招时序、收招续击／格挡及无伤害回放验证。
- `test/boss.test.js`：AI 决策与朝向、推挤、招式帧、格挡／受击、连续命中、特效生命周期及持续交锋验证。
- `test/jump-attack.test.js`：跳劈位移帧、双向命中、强击退与格挡滑行、必定待机、禁止连跳、突刺衔接与暂停验证。
- `test/round.test.js`：实际判定伤害、格挡韧性、跪倒输出窗口、死亡慢动作、结算、暂停与重开验证。
- `test/audio.test.js`：动画帧音效触发、命中与弹反互斥、随机音高范围、采样数据、延迟启用、静音／暂停、音效并发与调度验证。

画布逻辑尺寸 960×540，地面 y=420，角色统一 2 倍绘制，关闭图像平滑。玩家基础锚点 `(64,91)`，Boss 基础锚点 `(64,107)`。Boss 192×192 攻击帧的主体位于左下角 128×128，锚点为 `(64,171)`；水平翻转始终围绕身体锚点。跑步帧的脚底有少量像素差异，通过逐帧 groundY 保持落地。跳劈第 4～12 帧叠加一段抛物线腾空位移，最高额外上升 32 个画布像素，第 13 帧落地；身体和受击框同步升降，影子留在地面。腾空跟随动画时间，暂停和动画预览也同步生效。

游戏使用 requestAnimationFrame 渲染，玩家攻击与格挡使用 16fps，Boss 跑动使用 8fps，其他动作默认 12fps，与屏幕刷新率分离。图片启动时全部加载并缓存闪白剪影；窗口恢复时重置时间，单次渲染间隔的模拟时间限制在 100ms，避免后台切回后突然位移。

Boss 在固定锚点基础上下移一个原始像素（2 个画布像素）；先绘制 Boss，再绘制玩家，玩家始终处于前层。战败倒地后按身体基准 y=107 对齐，手掌／刀尖可以伸入地面前沿，不按它们的最低像素抬高整个身体。

新增动作：在 `ANIMATIONS` 添加尺寸、有效帧数和锚点配置，状态机会自动注册。`actor.update(dt, direction, ['attack'], targets)` 处理一次 J 输入并检测命中目标，`['defend']` 处理 K 输入；`actor.preview('attack')` 循环预览前 15 帧，可查看有效帧的攻击框，但预览不会触发命中。可在状态定义中加入 enter / update / exit 扩展战斗逻辑。
